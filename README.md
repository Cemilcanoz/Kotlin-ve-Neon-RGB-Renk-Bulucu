# Neon RGB Color Finder

A simple Kotlin Android app that lets users explore neon RGB colors interactively.

The app provides three sliders (R, G, B) to dynamically generate colors in real time. As the sliders move, geometric shapes (square, triangle, and circle) update instantly to reflect the selected color.

## Features

* Real-time RGB color mixing
* Neon-styled UI
* Live HEX + RGB value display
* Interactive sliders
* Dynamic shape color rendering

## Tech Stack

* Kotlin
* Jetpack Compose
* Android Studio

## Purpose

This project demonstrates interactive UI design, state management, and custom drawing using Jetpack Compose.
